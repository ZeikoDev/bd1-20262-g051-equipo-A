# Tarea 2 — Hoja de cálculo de resultados

Hoja de cálculo con el desarrollo de la normalización y el diccionario de datos de la **Experiencia de Aprendizaje 2 (EA2) — Modelo Lógico**.

| Entregable | Formato | Estado |
|---|---|---|
| [`20262-bd1-ea2-equipo-A-resultados.xlsx`](20262-bd1-ea2-equipo-A-resultados.xlsx) | `.xlsx` | Entregado |

El libro está organizado en cinco hojas:

| Hoja | Contenido |
|---|---|
| `TABLAS` | Inventario de tablas obtenidas de las entidades y relaciones del modelo relacional. |
| `1FN` | Tablas en Primera Forma Normal: atributos atómicos, clave primaria y claves foráneas. |
| `2FN` | Análisis de dependencias parciales en las claves compuestas y descomposiciones resultantes. |
| `3FN` | Análisis de dependencias transitivas e inventario definitivo del modelo lógico. |
| `DICCIONARIO DATOS (Genérico)` | Diccionario de datos del modelo en 3FN con tipos de dato independientes del motor. |
